# WebsiteTherapy Admin

Desktop app for [WebsiteTherapy](https://websitetherapy.com) site owners — manage your website by chatting with an AI assistant on your Mac.

## Download

Get the latest release: **[Latest release →](https://github.com/Websitetherapy/admin-releases/releases/latest)**

| Mac | Download |
|---|---|
| **Apple Silicon** (M1, M2, M3, M4) | `WebsiteTherapy-<version>-arm64.dmg` |
| **Intel** | `WebsiteTherapy-<version>.dmg` |

Not sure which you have?  → Click the Apple menu → "About This Mac" → Look at "Chip" or "Processor". Anything starting with "Apple M" is Apple Silicon. Anything with "Intel" is Intel.

## Install

1. Download the right `.dmg` file above.
2. Double-click the `.dmg` to open it.
3. Drag the **WebsiteTherapy** icon to your **Applications** folder.
4. Open the app from Applications. (First launch may show a Gatekeeper prompt — click "Open" to confirm.)
5. Sign in with the email address you used to sign up for WebsiteTherapy. You'll get a 6-digit code in your email.

## Auto-updates

The app checks for new releases every time you launch it. When a new version is available it downloads quietly in the background and applies on next quit — no manual reinstalls.
